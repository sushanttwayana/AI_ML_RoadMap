The fork: pick one branch

Both are real, hiring-in-2026 careers. ML Engineers build and ship models trained on data. AI Engineers build products on top of large language models. Pick the one that excites you — you can always cross over later, because the trunk is shared.

How to use this map

RULE 01

Finish the trunk before you choose

Prerequisites and ML Core are non-negotiable for both paths. Skipping them is why most self-taught journeys stall.

RULE 02

One project per station

Every station has a "Prove it". Tutorials don't get you hired — a GitHub full of small, finished projects does.

RULE 03

Phase 2 comes later — on purpose

Dashed ◌ topics are deliberately deferred. Return to them after your first capstone, or when a job description demands them.

Realistic pace: 10–15 hrs/week → trunk in ~4 months, branch in ~4–6 more. Faster is possible; slower is fine. Consistency beats intensity. · 2026 edition
